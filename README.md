# IMPERIUMTECH

Sistema multi-segmento em página única (HTML): Restaurante, Mercado/Loja, Barbearia/Salão e Oficina.

- PDV completo (unidade, peso, medida, comprimento), mesas e comandas, cardápio digital com KDS
- Agenda de barbearia/salão, encomendas, combos, atalhos por função
- Painel da Loja e Super Admin com isolamento total de dados por loja (regra do sistema)
- Porta pública de demonstração por segmento com captura de leads
- Páginas públicas por loja (cardápio, agendamento, vitrine) — exceto Oficina

Versão de demonstração validada. Dados de demonstração em memória; a fase de produção usa Supabase (banco, login e RLS por loja), gateways reais e domínio próprio.
